❗ RunTime ChezNet — Rules 🍔

Please read carefully. You must acknowledge each rule before entering.

  • No Cussing or Filter Bypassing Keep the chat clean and respectful at all times. This includes intentional misspellings, special characters, or creative workarounds designed to slip past the word filter. If someone would read it and know what you meant, it counts. Treat every member the way you'd want to be treated — disrespect in any form is not welcome here.
  • #dev-lab is for serious discussion only If you're going to post in #dev-lab, it had better be a formal, well-written bug report or a highly-requested feature suggestion. Casual conversation, jokes, or vague complaints don't belong there. Honestly, if you're unsure whether your message belongs there — it probably doesn't. When in doubt, stay out.
  • VC is a Work in Progress Voice Chat is experimental and may behave unexpectedly. Glitches, drops, and oddities are possible. It's recommended you avoid using VC entirely until the "WIP" label is removed. Don't report minor VC bugs in chat — use the profile suggestion box.
  • Feature requests go in Settings, not chat If you have an idea for something to add to RunTime ChezNet, do not post it in any channel. Open Settings → Profile → "What would you like to see added?" and write it there. Posting requests in chat will earn you a warn or a mute, no exceptions.
  • Keep your display name appropriate Your username and display name must be inoffensive and suitable for a general audience. Names that are vulgar, offensive, or designed to mock another user will be changed or removed by an admin without warning.
  • Theme requests have limits Themes may be added, removed, or changed at any time by the dev. Do not ask for a theme to be added or removed — those requests will be ignored. The only thing we'll consider is a request to modify a specific visual element of an existing theme.
  • No Spam Flooding the chat with repeated messages, walls of characters, or rapid-fire posting is not allowed. Spam disrupts the experience for everyone and will result in a mute, a warn, or a ban depending on severity. Repeat offenders risk permanent account deletion.
  • Zero tolerance for bullying RunTime ChezNet {} is a place to communicate — not to target, harass, or belittle anyone. If we catch you bullying another user, you can expect the fastest response of anything on this list. Mods: try to de-escalate. Admins: use your commands to silence the situation. If things get out of hand, the owner will step in directly.
