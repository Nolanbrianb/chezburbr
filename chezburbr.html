Chezburbr

Nolan Barringer. I build things in the browser, because it's the shortest distance between an idea and something I can actually click on.

Run your cursor through the letters. They'll get out of the way.

Almost everything I make is one file

No build step, no install, no folder of config I'll never open again. One HTML file, double-click it, it runs. If a friend wants it, I send them the file.

It's a constraint I picked on purpose. It keeps projects small enough to finish and weird enough to be worth finishing. A voxel game, an audio mixer, a whole operating system — all of them are just a page.

I don't work in tidy checkpoints. I'd rather build the whole thing loudly, break it, and figure out what it wanted to be on the way down.

Things I've built

The green line is what each one is mostly written in. Everything after the plus is along for the ride.

Muzix Lab
JavaScript + HTML, CSS, Muzix
An IDE for Muzix, a music programming language I invented. Loops, chord syntax, named blocks, an oscilloscope and a spectrum analyzer.
ChezCrush
JavaScript + HTML, CSS
An audio mixer with DJ decks, a triangle crossfader, LFO banks, bitcrush, key detection, and 51 hotkeys.
ChezSplit
Python + JavaScript, HTML
Sends my desktop audio to every speaker in the house at once, with per-device volume and drift correction. Started as a browser demo, ended up a desktop app.
Floatbox & Forge
JavaScript + HTML, CSS
A first-person physics sandbox and the world editor that feeds it, sharing a binary format I wrote called .waffle. Grapple hook, working toaster, map-wiping nuke.
VoxelCraft
JavaScript + HTML, CSS, Python
Minecraft in a single file. Caves, multiplayer, its own .vxw world format, and a Python shell to make it a real desktop app.
Nookyx
JavaScript + HTML, CSS
An operating system that is, structurally speaking, one web page. Accounts, spotlight search, terminal, weather.
Chez le Web
Python + JavaScript, HTML, CSS, JSON
My own browser, with its own extension format, its own permissions, and its own little store.
LEDGE
JavaScript + HTML, CSS, JSON
Seven tools I got tired of searching for, hidden behind a ghost handle on the edge of the screen. One of them encodes URLs through a Vigenère cipher.
Root Cause
JavaScript + HTML, CSS
A comedy terminal game. You type made-up commands at absurd problems and hope the trust meter holds.
Playbank
JavaScript + HTML, CSS
A play-money card terminal with OCR card scanning and several cashiers staying in sync at once.
Bullandish
JavaScript + HTML, CSS, Bullandish
A language I made up, a 500-word dictionary for it, and the translator that makes other people speak it.
